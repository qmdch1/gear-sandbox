# Gear Sandbox

브라우저에서 동작하는 기어/동력전달 물리 시뮬레이터입니다. 인볼류트(involute) 치형 수학을
바탕으로 기어가 실제로 맞물려 돌아가고, 12종의 서로 다른 동력전달 오브젝트를 자유롭게 배치·
연결해 하나의 동력원에서 여러 기계 요소로 힘이 전달되는 과정을 눈으로 확인할 수 있습니다.

## 주요 기능

- **정확한 맞물림**: 트라페조이드가 아닌 실제 인볼류트 치형 곡선을 사용해, 기어가 서로 겹치지
  않고 톱니가 정확히 맞물려 회전합니다. 압력각·기초원·이끝원/이뿌리원 계산까지 반영합니다.
- **12종의 오브젝트**: 평기어·헬리컬 기어·손잡이 기어(동력원)·베벨 기어·웜 기어·
  부하(플라이휠)·랙·유성기어 세트·래칫 기어·스프로킷(체인용)·풀리(벨트용)·차동장치.
  타입마다 형태와 재질 색상이 달라 한눈에 구분할 수 있습니다.
- **클릭 배치**: 팔레트에서 오브젝트를 고르고 뷰포트를 클릭하면 그 자리에 배치됩니다. 기존
  오브젝트와 겹치는 자리를 클릭하면 자동으로 옆으로 비켜 배치되며(단, 의도적으로 같은 축에
  포개는 커플링 배치는 그대로 허용됩니다), Esc로 배치를 취소할 수 있습니다.
- **원격 연결(체인/벨트)**: 서로 떨어진 스프로킷끼리는 체인으로, 풀리끼리는 벨트로 연결해
  동력을 전달할 수 있습니다.
- **내구도/마모**: 하중을 받는 오브젝트는 시간이 지나며 마모되고, 색상이 초록→노랑→빨강으로
  변하다 결국 파손됩니다.
- **진단**: 미연결·동력 없음·기하학적 겹침을 자동으로 감지해 사이드바에 표시하고, 클릭하면
  해당 오브젝트로 카메라가 이동합니다.
- **저장/불러오기**: 브라우저 로컬 저장소, 파일(JSON) 내보내기/가져오기, 서버 저장(이름을 붙여
  여러 레이아웃 저장·불러오기·삭제) 세 가지 방식을 지원합니다.

## 시작하기

```bash
npm install
npm run dev
```

`npm run dev`는 Vite 개발 서버(클라이언트, 기본 5173 포트)와 API 서버(기본 3001 포트)를 함께
띄웁니다. 브라우저에서 Vite가 알려주는 주소로 접속하세요.

다른 유용한 명령:

```bash
npm run build       # 프로덕션 빌드
npm test            # 전체 테스트 스위트 실행 (vitest)
npx tsc --noEmit     # 타입 체크만 실행
```

환경 변수:

- `API_PORT` — API 서버 포트 (기본 3001)
- `DB_PATH` — SQLite 데이터베이스 파일 경로 (기본 `server/data/layouts.db`)

## 조작 방법

| 동작 | 방법 |
|---|---|
| 오브젝트 배치 | 왼쪽 팔레트에서 종류 선택 → 뷰포트 클릭 |
| 배치 취소 | `Esc` |
| 오브젝트 선택 | 뷰포트에서 클릭 |
| 오브젝트 이동 | 선택 후 드래그 |
| 오브젝트 축 변경 | 선택 후 durability 패널의 X/Y/Z 버튼 |
| 오브젝트 삭제 | 선택 후 패널의 "삭제" 버튼, 또는 `Delete`/`Backspace` |
| 체인/벨트 연결 | 연결 모드 버튼 활성화 → 같은 종류의 오브젝트 두 개를 순서대로 클릭 |
| 전체 보기 | "전체 보기" 버튼 (배치된 모든 오브젝트가 한 화면에 들어오도록 카메라 리셋) |

## 아키텍처

- **`src/sim/`** — 렌더링/DOM에 의존하지 않는 순수 시뮬레이션 코어. 기어 타입 정의, 인볼류트
  맞물림 판정(`meshing.ts`), 매 틱(tick)마다 회전·마모·위상 정렬을 갱신하는
  `simulation.ts`, 기본 쇼케이스 레이아웃(`defaultLayout.ts`) 등.
- **`src/render/`** — Three.js 기반 3D 지오메트리·재질·씬 동기화(`sceneSync.ts`가 매 프레임
  시뮬레이션 상태를 실제 메시에 반영).
- **`src/interaction/`** — 드래그 이동, 클릭 배치 등 포인터 입력 처리.
- **`src/ui/`** — 팔레트, 진단 패널, 내구도 패널, 저장/불러오기 패널 등 DOM 기반 사이드바 UI.
- **`src/persistence/`** — 로컬 저장소·파일·서버 저장 포맷 직렬화/역직렬화.
- **`server/`** — Express + better-sqlite3 기반 레이아웃 저장 API (`/api/layouts`).
- **`tests/`** — 각 모듈별 단위 테스트와 `tests/integration/`의 전체 세션 통합 테스트.

## 테스트

이 프로젝트는 pytest 없이 vitest만 사용합니다. 물리 정확성(맞물림 위상, 기어비, 마모)부터
서버 검증, UI 상호작용, 반응형 레이아웃까지 폭넓게 테스트로 커버되어 있습니다.

```bash
npx vitest run                 # 전체 스위트
npx vitest run tests/sim       # 시뮬레이션 코어만
npx vitest run tests/server    # 서버 API만
```
